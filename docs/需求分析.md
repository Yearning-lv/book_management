# 需求分析

## 1. 项目概述

- 项目名称：图书管理系统
- 项目类型：综合性 Java 应用系统
- 开发目标：构建一个适合高校图书馆场景的书籍管理平台，实现账户、书目、馆藏、借阅与统计的一体化管理。
- 技术路线：
  - 前端：JavaFX + FXML
  - 后端：Spring Boot 3 + JPA
  - 数据库：MySQL 8
  - 通信：HTTP + JSON

## 2. 角色与权限

- 管理员
  - 管理工作人员与读者账户
  - 冻结/启用账户
  - 进行读者罚金结算
  - 查看全局统计面板
- 工作人员
  - 维护图书目录与馆藏副本
  - 处理借出、归还、续借等流通操作
  - 查看预约队列与系统统计
- 读者
  - 检索图书
  - 查看个人借阅记录
  - 发起预约
  - 续借自己的借阅记录
  - 查看预约状态

## 3. 功能需求

### 3.1 账户管理

- 工作人员账户新增、修改、删除
- 读者账户新增、修改、删除
- 读者扩展档案维护：借阅上限、证件状态、欠费余额
- 支持按账号、姓名、电话筛选

### 3.2 图书目录管理

- 图书基本信息维护：ISBN、书名、作者、分类、出版社、价格、关键词、简介
- 按分类、上架状态、关键词筛选
- 展示总藏量与当前可借副本数

### 3.3 馆藏副本管理

- 实体副本维护：条码、位置、成色、状态、采购日期、盘点日期
- 支持副本状态管理：可借、借出、预约待取、维修、遗失
- 图书总藏量与可借数量自动联动

### 3.4 借阅中心

- 工作人员办理借出与归还
- 系统自动计算应还日期
- 支持续借次数控制
- 自动标识逾期状态
- 归还时按逾期天数累计罚金

### 3.5 预约流程

- 读者在无可借副本时发起预约
- 系统维护预约排队序号
- 归还时自动将首位预约转为“待取”
- 支持取消预约

### 3.6 数据统计与可视化

- 系统概览：图书种类、馆藏副本、读者规模、在途借阅、逾期数、预约数
- 分类馆藏分布：按分类展示书目数与可借副本
- 借阅趋势：近 6 个月借阅变化
- 热门图书：借阅次数 Top 5

## 4. 非功能需求

- 输入校验：关键字段必填，金额与日期格式正确
- 稳定性：统一异常处理，错误时有明确提示
- 易用性：JavaFX 主框架支持菜单切换、标签式内容区、统一样式
- 可部署性：前后端均可独立打包为 JAR

## 5. 高分点映射

- 用户与权限管理：三角色权限控制
- 前端交互主框架：登录页、主导航、分角色菜单
- 核心 CRUD：账户、图书、馆藏、副本、预约
- 复杂业务流程：预约 -> 待取 -> 借出 -> 续借/逾期 -> 归还 -> 罚金
- 数据统计可视化：概览卡片 + 柱状图 + 折线图
