# 接口设计

所有接口均采用：

- 请求方式：`POST`
- 数据格式：`application/json`
- 统一请求体：

```json
{
  "data": {},
  "page": 1,
  "pageSize": 20
}
```

- 统一返回体：

```json
{
  "code": 0,
  "msg": "成功",
  "data": {},
  "total": 0
}
```

## 1. 认证接口

- `/api/auth/login`
  - 作用：登录系统
  - 参数：`username` `password` `role`
- `/api/auth/logout`
  - 作用：退出登录

## 2. 账户管理接口

- `/api/user/getUserList`
  - 查询账户列表
- `/api/user/getUserInfo`
  - 查询账户详情
- `/api/user/saveUser`
  - 新增/修改工作人员或读者
- `/api/user/deleteUser`
  - 删除账户
- `/api/user/payFine`
  - 读者罚金结算

## 3. 图书目录接口

- `/api/catalog/getBookList`
  - 查询图书列表
- `/api/catalog/getBookInfo`
  - 查询图书详情
- `/api/catalog/saveBook`
  - 新增/修改图书
- `/api/catalog/deleteBook`
  - 删除图书
- `/api/catalog/getCategoryOptions`
  - 获取分类下拉选项
- `/api/catalog/getPublisherOptions`
  - 获取出版社下拉选项

## 4. 馆藏副本接口

- `/api/catalog/getCopyList`
  - 查询副本列表
- `/api/catalog/getCopyInfo`
  - 查询副本详情
- `/api/catalog/saveCopy`
  - 新增/修改副本
- `/api/catalog/deleteCopy`
  - 删除副本

## 5. 借阅流转接口

- `/api/circulation/getBorrowList`
  - 查询借阅记录
- `/api/circulation/borrowBook`
  - 登记借出
- `/api/circulation/renewBorrow`
  - 续借
- `/api/circulation/returnBook`
  - 归还

## 6. 预约接口

- `/api/circulation/getReservationList`
  - 查询预约记录
- `/api/circulation/reserveBook`
  - 发起预约
- `/api/circulation/cancelReservation`
  - 取消预约

## 7. 统计接口

- `/api/stat/overview`
  - 系统概览
- `/api/stat/category`
  - 分类馆藏分布
- `/api/stat/trend`
  - 借阅趋势
- `/api/stat/topBooks`
  - 热门图书排行
