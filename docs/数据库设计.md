# 数据库设计

## 1. 设计原则

- 表名与字段名采用英文小写下划线风格
- 核心字段设置主键、唯一约束、外键约束
- 统一使用 `is_deleted` 做逻辑删除
- 角色、状态字段使用字符串编码，便于前后端展示

## 2. 主要数据表

### 2.1 `lib_user`

- 作用：统一账户表，保存管理员、工作人员、读者基础信息
- 主键：`user_id`
- 唯一约束：`account`
- 关键字段：
  - `role_code`：0 管理员，1 工作人员，2 读者
  - `status`：ACTIVE/FROZEN

### 2.2 `reader_profile`

- 作用：读者扩展信息
- 主键：`user_id`
- 外键：`user_id -> lib_user.user_id`
- 关键字段：
  - `reader_no`
  - `max_borrow_count`
  - `current_borrow_count`
  - `fine_balance`
  - `card_status`

### 2.3 `book_category`

- 作用：图书分类字典
- 主键：`category_id`
- 唯一约束：`category_code`

### 2.4 `publisher`

- 作用：出版社信息
- 主键：`publisher_id`
- 唯一约束：`publisher_name`

### 2.5 `book`

- 作用：图书目录主表
- 主键：`book_id`
- 唯一约束：`isbn`
- 外键：
  - `category_id -> book_category.category_id`
  - `publisher_id -> publisher.publisher_id`
- 关键字段：
  - `shelf_status`
  - `total_copies`
  - `available_copies`

### 2.6 `book_copy`

- 作用：实体副本表
- 主键：`copy_id`
- 唯一约束：`barcode`
- 外键：`book_id -> book.book_id`
- 关键字段：
  - `status`：AVAILABLE/BORROWED/RESERVED/REPAIR/LOST
  - `condition_level`

### 2.7 `reservation`

- 作用：预约排队记录
- 主键：`reservation_id`
- 外键：
  - `book_id -> book.book_id`
  - `reader_id -> lib_user.user_id`
- 关键字段：
  - `queue_no`
  - `status`：WAITING/READY/FULFILLED/CANCELED
  - `pickup_deadline`

### 2.8 `borrow_record`

- 作用：借阅生命周期记录
- 主键：`record_id`
- 外键：
  - `copy_id -> book_copy.copy_id`
  - `book_id -> book.book_id`
  - `reader_id -> lib_user.user_id`
  - `operator_id -> lib_user.user_id`
  - `reservation_id -> reservation.reservation_id`
- 关键字段：
  - `status`：BORROWED/OVERDUE/RETURNED
  - `borrow_date`
  - `due_date`
  - `return_date`
  - `renew_count`
  - `fine_amount`

## 3. 关系说明

- 一个读者账户对应一个读者档案
- 一个图书分类对应多本图书
- 一本图书对应多个实体副本
- 一本图书可以对应多个预约记录
- 一个实体副本可以在不同时期产生多条借阅记录

## 4. 关键业务约束

- 账号唯一，ISBN 唯一，副本条码唯一
- 借出时必须校验读者欠费和借阅上限
- 预约只允许在无可借副本时发起
- 归还时自动更新副本状态和图书可借数量
- 待取中的副本不计入可借数量
