# 部署说明

## 1. 环境要求

- OpenJDK 21
- Maven 3.9+
- MySQL 8.x
- Windows 10/11

## 2. 数据库初始化

1. 创建数据库并建表：

```sql
SOURCE sql/library_management_schema.sql;
```

2. 导入演示数据：

```sql
SOURCE sql/library_management_seed.sql;
```

3. 如果想在演示前一键恢复初始案例，直接运行根目录：

```bash
reset-demo-data.cmd
```

## 3. 后端启动

1. 修改 [`backend/src/main/resources/application.yml`](../backend/src/main/resources/application.yml)：
   - `spring.datasource.url`
   - `spring.datasource.username`
   - `spring.datasource.password`
2. 进入 `backend/` 执行：

```bash
mvnw.cmd clean package
java -jar target/backend-0.1.0-SNAPSHOT.jar
```

3. 默认端口：`8081`

## 4. 前端启动

1. 进入 `frontend/` 执行：

```bash
mvnw.cmd clean package
mvnw.cmd javafx:run
```

2. 如果后端不是本机 `8081`，可通过以下方式覆盖：

```bash
mvnw.cmd javafx:run -Dapi.baseUrl=http://127.0.0.1:8081
```

## 5. 演示顺序建议

1. 管理员登录，展示账户管理与统计面板
2. 工作人员登录，展示图书目录、馆藏副本、借出/归还流程
3. 读者登录，展示图书检索、预约、续借与个人借阅记录
